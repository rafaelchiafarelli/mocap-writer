Yellow · Fountain and scene numbers

Open, change one word, save: only that word changes

Fountain is the writer's own format. The reader keeps the exact source of every element, so a save rewrites only what you edited. Scene numbers are permanent: a scene keeps its number when others move around it.

Built from the as-built docs at commit 959bc3c (dev, 2026-10-31), updated from them after the bug fixes of the same day. When the code changes, the page is rebuilt from the docs.

Click a box (or Tab to it and press Enter) to see what it is, its files and what it hands to whom.

The numbering rule

  • A script with no numbers gets 1, 2, 3…
  • A new scene at the end gets the next whole number.
  • A scene inserted between two numbered scenes gets the next sibling of the scene before it, if that number is free before the next scene; otherwise the first child: levels alternate number and letter, 12, 12.A, 12.A.1.
  • There is no room between a scene and its own child, before scene 1, or next to a number in another tool's form: the save stops and offers Renumber all.
  • A number never comes back: a scene deleted after it was numbered leaves an OMITTED heading on save.
  • A heading gets its number as soon as it is finished (it has text and the cursor left it); until then the screen shows the number it will get, in parentheses.

Exercise

Three scripts, each with one new scene (shown as ?). What number does assign give it?

  1. 1, 2, ?, 3
  2. 1, 1.A, ?, 2
  3. 1, 2, 3, ?

Checked with scenenumbers.assign at this commit:

  1. 2.A: 3 is taken, so the scene becomes the first child of 2.
  2. 1.B: the next sibling of 1.A is still before 2.
  3. 4: at the end, the next whole number.

Check yourself

You change one word in scene 40 of a script written by another tool. Which bytes of the file change?
Only that element's: every other element is written from its raw source, with its pre (blank lines, boneyard, notes) in front. That is the byte-identical round trip.
Why is a moved and edited scene a new scene?
A move is found by the scene's exact text. If the text changed too, nothing proves it is the same scene, so its records stay on the old number, now an OMITTED heading.
Where does a film's title page come from when the script is saved?
From the film's front matter record: frontmatter.syncTitle writes the Fountain title block from it before every save of a film's script.
