The whole writer on one page

mocap-writer is Trelby, a screenplay editor from 2006, with a film folder and its records built around it. Read the map left to right: the program starts, a window holds one editor per script, the editor works on a screenplay model, and the model is saved as Fountain into a film root that other Mocap Studio programs read.

Built from the as-built docs at commit 959bc3c (dev, 2026-10-31). When the code changes, the page is rebuilt from the docs.

Click a box (or Tab to it and press Enter) to see what it is, its files and what it hands to whom.

The pages

Each layer has its own page, in the order a change usually travels:

  • The model (blue): lines, elements, commands, undo, pagination.
  • The editor (pink): startup, the window, a key press from the keyboard to the screen.
  • Fountain & numbers (yellow): the file format and the permanent scene numbers.
  • The film root (green): film.json, the bible, the change log, missing files, Find props traced to disk.
  • Around the code (goldenrod): Docker, the tests, branches, the as-built rule, a review checklist.

The colours are the order screenplay revision pages go through, white first.

Check yourself

Which parts never import wx, and why does that matter?
The model (screenplay, line, undo), fountain, scenenumbers, film, bible and the other record modules. The test suite runs them without a display, so everything that matters for the files on disk is tested; only dialogs and painting need the real window.
Where does the script's text live, and where do its sets and characters live?
The text lives in script.fountain (the film's script part). The sets, characters, props and wardrobe live as item.json folders under bible/. The script never holds record data: records point to scenes by their permanent number.
Why does the writer read its own records through mocap-contracts instead of plain JSON?
So the writer and the pre-production agents agree on one format, defined once in the Harpia schema: a file that breaks the contract is refused on read and never written.
