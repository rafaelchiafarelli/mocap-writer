# mocap-writer — initiatives (execution order)

Source: Rafael's review of unmodified Trelby (2026-10-23). Bugs found there
go as fix branches, not initiatives (splash that never closes, tooltips that
start off-screen).

1. **editor-ux** — zoom, dark theme, Tab order, capitalized words in Action
2. **fountain-native** — open/save Fountain as the native format; scene ids and numbering; notes on text spans
3. **film-bible** — the maps (sets, characters, props, wardrobe) as folders in the film root
4. **story-structure** — where we are in the story (acts, beats): a study first

`film-bible` needs `fountain-native/scenes` (scene ids). `editor-ux` needs nothing.
