## 4. Requests addressed to the creator

- **Depends on:** 3
- **Contract:** open requests whose `to` is `creator` are listed in the
  review view with their items and scenes; the creator marks one `done`
  or `declined` with an optional answer (`answered_by` creator). Creating
  an item the request asks for stays the creator's own action in the
  bible panel.
- **Tests:** list and answer a request on the test database
